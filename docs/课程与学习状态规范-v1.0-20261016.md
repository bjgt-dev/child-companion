# 课程与学习状态规范 v1.0

- 生效：2026-10-16；依据 V1.1 第四章 4.3
- 对应代码：`mvp/schema.sql`（表结构）、`mvp/learning_store.py`（读写）

## 一、学习目标记录（learning_goals）

| 字段 | 说明 |
|---|---|
| domain_id | 能力领域（1–10，对应能力地图） |
| title | 具体目标，如"数字与数量对应" |
| prerequisites | 前置能力 |
| status | 掌握状态（见下） |

## 二、掌握状态（6 态）

`未接触 → 正在探索 → 正在学习 → 初步掌握 → 多次观察后基本掌握 → 需要重新检查`

迁移规则（代码 `next_mastery`）：
- 答对：未接触/探索→学习；学习→初步掌握。
- 新场景迁移成功累计 **2 次** → 基本掌握；1 次只到初步掌握。
- 迁移失败 → 需要重新检查；退回实物示范。
- 看完视频 / 一次答对 / App 过关 **永不**直接判掌握。
- 拒绝 / 想停 / ASR 错误 / 不知道 → 状态不变（非知识信号不升降）。

## 三、证据分级（observations.evidence_kind，强制标注）

- **A 家长确认**：家长明确确认的信息。
- **B 互动观察**：互动中实际观察到的表现。
- **C 未验证推测**：尚未验证的推测，展示时明确标"推测"。

一次回答、一次情绪表现 → 只记 B，不贴永久标签（C 更不允许转正）。

## 四、观察记录字段（observations）

performance（实际表现）/ help_level（独立/少量提示/较多帮助/全程协助）/
independent（是否独立完成）/ transferred（是否新场景迁移）/
observed_at / note。

## 五、更新规则

- 每次活动结束按"统一教学闭环 5 问"复盘后写入。
- 家长可查看全部记录；可**纠正**（留痕：原值→纠正值+原因）、可**删除**。
- 不做儿童间比较，不做能力排名。
- 复习安排进 review_schedule（默认 2 天，换材料重测）。
