# 真人首测决策记录 v1.0（2026-10-16）

> 首次真实儿童语音陪伴实测（约20分钟），链路：孩子语音→家长转文字→Twt2026→TTS短句MP3→家长播放。
> 结论先行：对话设计验证有效，但暴露"和小度没区别"问题，差异化 P0 已立项。

## 已定决策

### 1. 语音播报方案（家长已选）
- 方式：Twt2026 生成语音文件（MP3），不走 App 自动朗读（账号无实时语音通话）。
- 规则：短句（TTS 2-3秒级）+ Warm 中文语音（avocado_v2:MAI_01）。
- 备选：活泼/开朗/讲故事 3 个试听已发家长，待孩子拍板。

### 2. 教学模式：目标驱动（家长纠正后确立）
- 前半段问题：跟着孩子兴趣走，无教学主线 = 闲聊。
- 纠正后：每次对话定一个小目标。今晚目标=水果口味英语，载体=冰淇淋店角色扮演。
- 要求：每句话为目标服务；目标+载体+即时反馈三件套。

### 3. 差异化 P0（vs 小度）
- 小度：每次陌生、陪聊、黑盒。我們必须：记得（"还记得昨天学的 strawberry 吗"）、有目标、会长大（掌握状态推进）、家长看得见（学习档案+家长视图）、是孩子的（名字/声音/身体自定）。
- 验收标准：差异化在每次对话中可见，不能只存在于文档。

### 4. "变魔法"=图片生成
- 实测 2 张（平底锅卡梅利多、打怪兽魔法），孩子反响热烈，已成为陪伴核心能力。
- 设备屏显：BOX-3 有 2.4 寸触摸屏；xiaozhi 默认固件只显示表情，自定义图片需改固件（排硬件联调）。

### 5. 延迟基线（实测）
- ASR 0.35s；LLM 3-8s（看回复长短）；TTS 2-4s。真实环境一轮约 5-10s，目标 5s 内。
- 优化方向：短回复、Groq key、流式输出。
