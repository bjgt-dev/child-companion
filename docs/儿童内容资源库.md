# 儿童陪伴 agent · 儿童内容资源库

项目初衷（2026-10-18 董事长定）：**创造沉浸式英语环境，陪孩子口语表达**。
本库对标小度儿童内容分类，是六大模块的内容弹药库：M1 英语过家家 / M2 为什么接龙 / M0 认字 / 日常陪伴。

收录标准：
- 5-6 岁适宜：语速慢、重复多；鼓励开口（跟唱/跟说）优先于被动观看。
- 内容安全最高标准：无暴力、无软色情、无消费主义诱导、无恐怖惊悚；进 resources.py 审核门禁后方可进教学。
- 优先免费、可长期访问；需付费的单独标注，不默认采购。
- **资源库即白名单**：agent 只许推荐库内验证条目，不许推荐库外链接。

收录流程：搜集（Noesis/团队/董事长投喂）→ 验证真实性+分级+安全初筛 → 编目入库 → 技术部接入 resources.py 审核门禁。

缓存策略：目录只放链接；音频（儿歌/故事/英语跟读）下载缓存在 VPS（/data 下独立目录），iPad PWA 端缓存核心子集；视频只放链接、在线播（版权与体积原因）。支撑 v2.1"断网可播预置故事"（断网不砖）。

运行时原则：**被问到时不现场搜索**。库里有的直接用（音频走 VPS 缓存，响应快）；库里没有的，记入待搜集清单，每周迭代入库。现场搜索=把内容安全交给搜索引擎，不符合白名单铁律。

## 九、竞品借鉴（小度 / 豆包，2026-10-18 研究）

核心结论（完整对照表见 hidden_files/首轮资源搜集-20261018.md）：
1. **资源库即白名单**：agent 只推荐库内条目，对标小度内容过滤——已定为本库铁律。
2. **按场景打包而非按来源罗列**：学小度"动画英语"（起床英文/吃饭英文/洗澡英文），二期按场景重组。
3. **每个条目配家长提问话术**：学豆包"别直接给答案"，把被动观看变成开口互动——二期字段。
4. **固定仪式栏目**：睡前故事、晨间国学固定入口，培养习惯。
5. **"为什么接龙"设固定高优先级入口**：学小度知识百科推荐位；答不上来转 AI 搜知识兜底并记录。
6. **agent 设"儿童模式"状态**：一键进，退出需家长确认——记入 P2 需求候选。

诚实标注：小度官方站本轮抓取失败，信息来自多家独立媒体交叉验证；豆包主 App 青少年模式无官方独立介绍页，如实标注未找到。
