# 教学策略库 v1.0

- 生效：2026-10-16；依据 V1.1 第四章 4.2
- 对应代码：`mvp/strategy_engine.py` 的 `STRATEGIES`（key 固定，换模型不换策略）

| key | 策略 | 适用信号 | 用法 | 禁忌 |
|---|---|---|---|---|
| explore | 自主探索 | 无明确目标时 | 跟随孩子兴趣开放探索 | 不预设标准答案 |
| socratic | 启发式提问 | 不知道答案 | 简短适龄问题引导发现 | 问一次不会就转直接解释，不连环逼问 |
| scaffold | 逐级提示 | 答错 / 部分答对 / ASR 错误 | 从最少提示开始逐步加；先排查听懂/ASR/实物 | 不把 ASR 错误记为知识错误 |
| explain | 直接解释 | 要求解释 / 连错 2 次 | 讲清楚，再降难度 | 不为启发而拒绝解释 |
| demo | 实物示范 | 抽象概念卡住 / 迁移失败 | 积木/手指/实物具象化 | 不只讲结论 |
| game | 游戏化练习 | 需要重复练习 | 包进游戏规则 | 不变成刷题 |
| transfer | 现实情境迁移 | 答对后 | 换场景换物品验证 | 答对一次不用此策略就判掌握 |
| review | 间隔复习 | 迁移成功后 | 隔天/几天换材料再测 | 不当天重复刷 |
| adjust | 难度调整 | 连错 / 太容易 | 降难度或升难度 | 不一次跳两级 |
| comfort_pause | 情绪安抚与暂停 | 拒绝 / 烦躁 | 安抚，可转轻松陪伴 | 不强迫作答 |
| wrapup | 总结和结束 | 想停止 / 活动完成 | 总结发现，允许结束 | 不为活跃度制造新任务 |

## 决策优先级（引擎规则摘要）

1. 安全/情绪信号优先：`wants_stop` → wrapup；`refuse` → comfort_pause。
2. 输入不可靠优先：`asr_error` → 换方式重问，不记错。
3. 明确要解释 → 直接给。
4. 答错 → 先排查（听懂？识别？实物？）再逐级提示；连错 2 次转直接解释 + 降难度。
5. 答对 → 不庆祝了事，转迁移任务；迁移成功 2 次才算基本掌握。
