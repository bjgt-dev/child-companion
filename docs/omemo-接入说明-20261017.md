# omemo 对话记忆接入说明

日期：2026-10-17
状态：已接入主流程并验证

## 架构

```
┌─────────────────┐     ┌──────────────────┐     ┌──────────────┐
│ 陪伴主流程       │     │ omemo 记忆代理    │     │ 上游 LLM      │
│ teach_loop.py   │────▶│ localhost:8100   │────▶│ sub2api       │
│ llm_client.py   │     │ (记忆存取+注入)   │     │ agnes-3.0-flash│
└─────────────────┘     └──────────────────┘     └──────────────┘
                              │
                              ▼
                       ┌──────────────┐
                       │ 记忆存储      │
                       │ /home/ubuntu/ │
                       │ omemo/data/  │
                       └──────────────┘
```

- 陪伴代码**零改动**：`llm_client.py` 本就是环境变量驱动，只改配置
- 所有 LLM 调用经 omemo（OpenAI 兼容接口），omemo 自动记忆对话事实并在后续对话中注入召回
- 上游仍是 sub2api 的 agnes-3.0-flash，key 存于 omemo 自身配置

## 配置

### 1. omemo 服务（systemd user service，已启用开机自启）

位置：`/home/ubuntu/.config/systemd/user/omemo.service`

```ini
[Unit]
Description=omemo 对话记忆代理（儿童陪伴项目）
After=network.target

[Service]
Type=simple
WorkingDirectory=/home/ubuntu/omemo
Environment=PORT=8100
ExecStart=/home/ubuntu/omemo/venv/bin/python main.py
Restart=always
RestartSec=5
StandardOutput=append:/home/ubuntu/omemo/omemo.log
StandardError=append:/home/ubuntu/omemo/omemo.log

[Install]
WantedBy=default.target
```

注意：omemo 默认端口 8080 与 sub2api 冲突，故用 `PORT=8100`。

管理命令：
```bash
systemctl --user status omemo    # 查看状态
systemctl --user restart omemo   # 重启
systemctl --user stop omemo      # 停止
tail -f /home/ubuntu/omemo/omemo.log  # 看日志
```

### 2. 陪伴端配置

`/home/ubuntu/child-companion/mvp/omemo.env`：
```bash
LLM_BASE_URL=http://localhost:8100/v1
LLM_API_KEY="local-omemo-placeholder"  # 本地占位，omemo 不校验
```

`/home/ubuntu/child-companion/mvp/run_with_memory.sh`（wrapper）：
```bash
./run_with_memory.sh python3 teach_loop.py
```

## 验证结果（2026-10-17）

1. **记忆存入**：对话"记住：我最喜欢的水果是香瓜" → omemo 记录成功
2. **记忆召回**：全新进程问"你还记得我最喜欢的水果是什么吗？" → 正确答出"香瓜"
3. **服务自启**：systemd `Restart=always` + `enabled`，重启后自动恢复（实测 restart 后 8 秒恢复服务）
4. **回归测试**：Phase 0-5 共 32 个测试全部通过（11+8+3+4+2+4）

## 回滚方法

任选其一：

1. **临时回滚**（单次运行）：直接运行不经过 wrapper
   ```bash
   cd /home/ubuntu/child-companion/mvp
   python3 teach_loop.py  # 不加载 omemo.env，走原逻辑
   ```
2. **彻底回滚**：删除或注释 `omemo.env` 中的两行，`llm_client.py` 恢复 stub/直连模式
3. **停 omemo 服务**：`systemctl --user stop omemo && systemctl --user disable omemo`

## 已知限制

- omemo `builtin` 自动提取模式需模型输出 `<memory>` 标签，当前模型不稳定；手动记忆可靠
- omemo 数据存于 `/home/ubuntu/omemo/data/`，备份时一并拷贝
