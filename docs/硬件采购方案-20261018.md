## 一、别人怎么做电池优化（对标研究）

| 产品 | 电池/续航（公开数据） | 省电核心做法 |
|---|---|---|
| 小天才电话手表 Q3A/Z12 | 760–780mAh；正常使用 1–2 天，待机约 7 天；磁吸充电，充满约 100 分钟 | 按键/抬腕唤醒（非语音常开）；定位按间隔上报；视频通话最耗电——**耗电功能按需开** |
| 火火兔故事机 G6 | 3.7V 800mAh（2.96Wh）；4Ω/3W 喇叭 | **本地 TF 卡离线播放，不联网**——这是故事机续航长的根本原因；按键操作 |
| 牛听听读书牛 | WiFi 熏教机，Type-C 充电 | 下载后离线熏听 + 定时关机；联网只在同步内容时 |
| 点读笔类（小熊等） | 锂电池，连续播放约 6 小时 | **闲置 3 分钟自动关机**；低电量红灯 + 30 秒后自动关机；2–3 个月不用的话要补电防过放 |
| 小度/小爱智能音箱 | 无电池，**常通电** | always-on 语音唤醒的代价就是插电——便携版极少，这是行业用脚投票的结果 |
| 行业唤醒芯片 | Syntiant NDP100：唤醒识别时 <150µW；唯创 WT2606A：双核 DSP 本地唤醒 | 真·超低功耗唤醒靠**专用神经网络芯片**，不是靠主 CPU 空转 |

**结论（四条铁律）：**
1. **便携儿童设备没有一家做"语音常开唤醒"**——全是按键/触摸唤醒 + 睡眠。语音唤醒只出现在插电设备上。
2. **离线是省电之王**：火火兔/牛听听把内容放本地，续航直接翻倍。我们的音频缓存策略（VPS + 终端本地）与此同构。
3. **闲置自动睡**：3 分钟无交互进 deep sleep 是行业标准动作。
4. **耗电排序**：喇叭播放 > WiFi 传输 > CPU > 麦克风待机。优化先砍大头：限音量、音频压缩（Opus）、WiFi 按需建连。

## 三、系统架构（文字图）

```
[孩子] ⇄ (说话/听)
  ┌─ 终端：斑梨 ESP32-S3 MAX（小智固件）────────┐
  │ 按键/触屏唤醒 → 双麦录音 → Opus 压缩         │
  │   → 室内 WiFi / 户外 4G（ML307R，自动切换）  │
  │   ← 音频流 ← VPS                            │
  │   → NS4150B → 喇叭播放（限 85dB）           │
  │ 电源：3000mAh（MX1.25 直插）；3分钟无交互    │
  │ deep sleep；户外模式默认关屏纯语音           │
  └─────────────────────────────────────────────┘
              ↕ WiFi（室内）/ 4G（户外）
  ┌─ 自家 VPS（甲骨文云 2核12G）─────────────────┐
  │ nginx → voice-app → sherpa-onnx ASR（本地）  │
  │       → strategy → LLM → edge-tts → 音频流   │
  │ /data/child-audio 音频缓存                   │
  │ 口径：语音数据默认不出内网（v2.1 董事长签字） │
  └─────────────────────────────────────────────┘
```

设计要点：
1. 终端只做**采集 + 播放 + 缓存**，识别/对话/合成全在 VPS（口径 A：数据不出自家服务器）
2. 音频 Opus 压缩后传输，带宽省 70%，WiFi 发射时间短 = 省电
3. 睡前故事等高频内容缓存在终端 Flash（16MB 可存约 2 小时 Opus 音频），断网可播

## 四、电池优化策略（落地清单，2026-10-18 晚户外专项增补）

### 为什么手机可以做得那么好（我们学不来的三样）
1. **制程碾压**：手机 SoC 3–4nm，ESP32-S3 是 40nm——同样算力功耗差一个数量级，这是物理代差。
2. **大小核架构**：手机有专用能效小核 + 低功耗岛（熄屏听歌/计步不吵醒大核）；S3 只有两个同构 LX7，没有能效分层。
3. **基带深度睡眠**：手机基带支持 PSM/eDRX（LTE-M/NB-IoT 可睡几小时只醒几毫秒收寻呼）；Cat.1 的 ML307R 不支持 PSM，只能靠我们手动断电。
4. **屏幕**：手机 OLED+LTPO（只亮有像素的点，刷新率 1–120Hz 自适应）；我们的 3.5 寸 LCD 背光一开就是 150–250mA 常亮。
5. **系统级调度**：Android Doze 把后台任务批量对齐到维护窗口，网络请求不碎片化。我们固件里要自己实现"攒一批再干"。

### 我们能抄的 6 招（按收益排序，全部可落地）
1. **4G 模块按需断电**（收益最大）：在家/闲置时 `AT+CPOWD` 彻底断电或 `AT+CFUN=0`（几 mA）；出门才上电。冷启动入网 10–30s，孩子可接受。**不要让 4G 待机空转**——它是户外第一耗电户。
2. **户外模式关屏纯语音**（已定）：屏+4G 双开是 2–3 小时，关屏单 4G 是 3–5 小时。15 秒无操作自动息屏。
3. **ESP32-S3 睡眠三件套**（IDF 原生，照抄官方配置）：
   - 无交互 3 分钟 → deep sleep（<10µA），**按键/RTC GPIO 唤醒**，唤醒后 reboot 约 1–2s；
   - 在家 WiFi 待机用 `WIFI_PS_MAX_MODEM`（Modem-sleep，保持连接，RF 周期性关闭）；
   - 开 `CONFIG_PM_ENABLE` + tickless idle，空闲自动进 light-sleep（S3 关 CPU 省约 650µA）。
   - ⚠️ 社区已知坑：deep sleep 有小概率睡死不醒，workaround 是唤醒后 `delay(500ms)` 再读 RTC 内存。
4. **不做语音常开唤醒**：ESP-SR WakeNet 常驻约 30–40mA，手机敢做是因为有专用低功耗岛。**我们用按键唤醒**，这是行业标准动作（小天才/点读笔全是按键唤醒）。
5. **本地缓存优先**：睡前故事/儿歌放 Flash/TF 卡，户外能播的不走 4G（已建 /data/child-audio，终端侧同步子集）。
6. **电池选型**：5000mAh（重度户外）/ 3000mAh（日常）；**低温提醒**：冬天户外锂电化学活性下降掉电快，手机也一样，这是化学限制不是 bug，-10℃ 以下建议放衣服内兜。

### 原落地清单（保留）
1. **唤醒**：按键唤醒为主
2. **联网**：WiFi 按需建连，对话结束即断；不用 MQTT 长连接（心跳是隐形耗电）
3. **播放**：优先播本地缓存；音量软件限 85dB（护耳 + 省电双收）
4. **充电**：Type-C；低电量 20%/10% 两档语音提醒；长期不用每月补一次电（防过放）
5. **儿童安全**：电池仓螺丝固定；外壳圆角；无小零件脱落风险

## 八、服务端决策：xiaozhi-esp32-server 当协议壳（2026-10-18 21:38 董事长定）

**方向**：站在前人基础上继承，不自己从零造协议栈；吸收小智架构长处，保持我们自己的教育产品特色。

### 继承小智的（基础设施层）
- WebSocket 小智通信协议（斑梨板烧小智固件直连）
- 实时打断（barge-in，全双工流式）
- VAD 语音活动检测
- 设备管理后台（Vue console）、OTA 固件升级
- 意图识别框架（LLM intent + function call 机制）

### 我们自己的（产品层，不动）
- ASR：sherpa-onnx 本地（口径：孩子语音数据默认不出内网，v2.1 签字）
- 教育大脑：strategy_engine 11 策略 + M0–M5 六大模块状态机
- 三层护栏：前置过滤 / prompt 约束 / 后置跨模型审核 + 安全词转家长
- TTS：edge-tts（现有 warm 系音色偏好）
- learning_store 长期记忆 + P0b 30 句题库 / 安全评估集 v1/v2（验收标准）

### 落地路径
1. 技术部先评估 xiaozhi-esp32-server（xinnan-tech）插件机制：ASR / LLM / TTS 三个插拔点的代码位置与替换工作量，输出评估报告（已派单，见 hidden_files）。
2. 评估通过后：部署全本地版（本地 ASR + 我们的教育大脑 + 护栏），默认云配置一律不用。
3. voice-app（HTTP）保留为 Web 端/iPad 测试通道；ESP32 终端走小智协议。两条腿走路。
