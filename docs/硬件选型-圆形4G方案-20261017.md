# 硬件选型报告：圆形 4G 方案（2026-10-17）

> 用户需求：ESP32S3 + 3.5寸触屏 + 摄像头 + 外壳 + 4G，偏好圆形设计

## 结论先行

**市面上不存在"3.5寸圆形屏+4G+摄像头"四合一的现货产品。** 圆形屏最大只做到 2.8 寸（480×480），3.5 寸全是方形屏；带屏的板子都不带 4G，4G 必须外接模块（小智固件原生支持，无需魔改）。

两个候选，按优先级排序：

| | 方案 A：微雪 3.5B-C | 方案 B：微雪 2.8C 圆屏 |
|---|---|---|
| 屏幕 | 3.5寸方形触屏 320×480 | **2.8寸圆形触屏 480×480** ✅用户偏好 |
| 摄像头 | OV5640（500万像素，套装自带）✅ | ❌ 无摄像头接口 |
| 外壳 | ✅ 套装自带 | 需另配/无官方壳 |
| 4G | ❌ 需外接模块 | ❌ 需外接模块 |
| 小智固件 | ✅ 第三方明确标注支持 | ⚠️ 需按 AMOLED-1.8 同类移植 |
| 预估总价 | ¥350~450（含4G模块） | ¥300~400（含4G模块） |

**推荐方案 A**（3.5B-C）：摄像头是硬需求（视频通话/视觉互动），2.8C 没有摄像头直接出局。圆形外观可用定制硅胶套/3D 打印圆壳弥补。

## 4G 方案（外接模块）

市面上**没有任何**"3.5寸屏+4G一体"的 ESP32-S3 板。4G 必须外接，但这是官方支持的路线：

- **小智固件原生支持**：官方 README 明确写 "ML307/EC801E or NT26 Cat.1 4G networking"，固件层已做好 Wi-Fi/4G 双网切换。
- **推荐模块**：合宙 Air724UG / 移远 EC801E 的 USB 开发板（Cat.1），淘宝约 **¥50~80**，经 USB/UART 接 ESP32-S3，用 PPP 拨号。
- **微雪一体方案**（仅作参考，不符合屏幕需求）：ESP32-S3-SIM7670G-4G（SKU 26632），ESP32-S3 + SIM7670G 4G + 摄像头接口，**无屏幕**。https://docs.waveshare.net/ESP32-S3-SIM7670G-4G/
- **使用场景**：户外无 Wi-Fi 时 4G 在线；在家走 Wi-Fi。SIM 卡用物联网卡（年付约¥30~50）。

## xiaozhi-esp32 固件兼容性结论

| 板子 | 官方支持状态 | 结论 |
|---|---|---|
| ESP32-S3-Touch-LCD-3.5B | 未在官方 README 部分列表中，但 138 个板卡目录中有大量同架构（ESP32-S3R8+ST7796/AXS15231B）板型；**多家第三方（Elecrow/alexnld/spotpear）明确标注"Support Xiaozhi AI"** | ✅ 可烧录，选最接近的 3.5 寸板型固件，屏幕/触摸驱动大概率直接兼容 |
| ESP32-S3-Touch-LCD-2.8C（圆屏） | 官方列表中有同门兄弟"微雪 ESP32-S3-Touch-AMOLED-1.8"（圆屏） | ⚠️ 大概率可移植，需按自定义板卡指南（Custom Board Guide）配 480×480 圆屏驱动 |
| 4G（ML307/EC801E） | ✅ 官方 README 原生支持 | ✅ 固件层已支持 |

**风险提示**：3.5B 的 AXS15231B 是较新的 QSPI 屏驱动（老版 3.5 用 ST7796），烧录前先用官方"免开发环境烧录"流程选最接近板型实测，不行再按自定义板卡指南移植（约半天工作量）。
