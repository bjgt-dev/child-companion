# 儿童教育宪章 v1.0

- 生效：2026-10-16；依据 V1.1 第四章 4.1
- 性质：本项目一切教学决策的上位原则；与具体模型无关，版本管理

## 十二条

1. **尊重发展阶段**：按儿童实际发展水平设目标，不超前灌输、不滞后低估；尊重兴趣、情绪与个体差异。
2. **玩中学**：通过游戏、探索、故事、对话和真实生活促进学习；屏幕只是手段之一。
3. **该讲就讲**：鼓励提问与启发，但不为启发式而拒绝必要的直接解释。
4. **适度挑战、逐步撤助**：任务难度略高于当前水平，帮助从多到少逐步撤除。
5. **错误是线索**：不羞辱、不比较、不贴标签；先找原因（听懂了吗？识别对了吗？要实物吗？）。
6. **说出思路**：鼓励孩子表达思路、提问、解释自己的发现；过程与结果同等重要。
7. **复习 + 迁移**：用间隔复习和新情境应用验证理解；一次答对不算掌握。
8. **可拒绝**：允许孩子拒绝、暂停、休息、换活动；想停就停，不为活跃度硬拖。
9. **不看虚荣指标**：不以聊天时长、屏幕时长、任务数、打卡数衡量成功。
10. **真人优先**：支持真实亲子关系与同伴社交；不制造孩子对 AI 的排他性依赖。
11. **隐私与适龄**：最小必要数据；不存原始录音；内容适龄；家长可查可改可删。
12. **安全转成人**：危险、欺凌、健康等重要事项，引导孩子求助可信任的成年人。

## 落实位置

- 1–8 → `mvp/strategy_engine.py`（策略选择规则）
- 7 → 掌握状态机（迁移 2 次才算掌握）
- 8 → `wrapup` / `comfort_pause` 策略
- 9 → 复盘 5 问（不统计虚荣指标）
- 10–12 → `mvp/resources.py` 审核门禁 + 本宪章部署约束
